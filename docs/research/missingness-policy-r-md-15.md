## 4. Formal Missingness Policy Specification (`R-MD-15`)

### Invariant 1: Absolute Prohibition of Standalone Indicator Features
Explicit binary flags of the form `is_missing_<feature>` are strictly prohibited from production feature matrices. Adding explicit indicators produces zero statistically significant pinball loss reduction while increasing parameter count and introducing risk of spurious behavioral penalties.

### Invariant 2: Non-Judgmental Progressive Disclosure
Missing inputs must never be interpreted as an indicator of candidate unfitness, lower competence, or diminished market value. Missingness represents user privacy choice under DPDPA 2023, not an unobserved personal attribute.

### Invariant 3: Nested Model Routing over Artificial Imputation
When a query lacks Level 1, Level 2, or Level 3 information, the serving runtime routes the query to the dedicated nested model ($M_0, M_1, M_2$) trained exclusively on observed features (ratified under T6.03b). The platform never synthesizes imputation values or missingness indicator flags for omitted tiers.
