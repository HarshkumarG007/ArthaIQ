### 1. Read this first

- **What we are building:** **ArthaIQ** — a personalized compensation intelligence and decision-support tool for India tech careers. It returns an empirical pay range (P10, P50, P90) with an evidence summary and transparent prediction support, and abstains when evidence is thin. It is not an appraisal, an offer or a guarantee.
- **Six prediction targets, kept separate:** PT1 market pay for a profile, PT2 comparable cohorts, PT3 offer distribution, PT4 negotiation scenarios, PT5 transition scenarios, PT6 current pay versus benchmark. Only PT1, PT2 and PT6 are in the first release.
- **Where we are:** Phase 4 (Baselines and leakage-resistant evaluation) is in progress. T4.01, T4.02, T4.03, T4.04, T4.05, T4.06 completed. **NEXT TASK: T4.07 (Experiment records and `make experiment`: seeds, configs, snapshot ids, timings and memory).** (T0.00-T0.07 done; Gate G0 ratified; Phase 1 T1.01-T1.13 done; Gate G1 ratified; Phase 2 T2.01-T2.11 done; Gate G2 ratified; Phase 3 T3.01-T3.15 done; Gate G3 ratified 2026-10-16; T4.01 done 2026-10-16; T4.02 done 2026-10-16; T4.03 done 2026-10-17; T4.04 done 2026-10-17; T4.05 done 2026-10-17; T4.06 done 2026-10-17).
- **Scope ratified (Decision):** India technology roles (software, data and ML), measure `guaranteed_cash_annual`, INR nominal (LPA). Deliberately limited initial occupational scope. Ratified at Gate G2 (ADR-0001, ADR-0002, PRD v1.0); supported by primary data acquisition programme (T2.10).
- **What exists:** repo scaffold, initial configs, doc suite v0.2, PRD v1.0, ADR-0001 v1.0, ADR-0002 v1.0, ADR-0003 v1.0, ADR-0006 v1.0, canonical schema v1.0.0 (`CompensationObservation`, Pandera dataframe schema, enums, entities), settings & PII-masked logging, normalization engine (`annualization`, `denomination`, `currency`, `deflation`, `titles` taxonomy & rule-based normalization engine, and `levels` seniority mapping with soft labels & ambiguity audit), quality engine (`profiler`, `coverage`, `sufficiency`, `target_prototype`, `dedup` exact duplicate, person & employer entity clustering & reporting engine, `quarantine` outlier and inconsistency quarantine engine with mathematical count reconciliation proof and halt threshold, `scoring` SQSF 10-dimension source quality scoring engine with provenance tier mapping and observation attachment, and `report` automated data quality & contract verification engine), synthetic test fixture generator (`tests/fixtures/synthetic.py`) with strict `is_synthetic = True` flagging and isolation guards (`block_synthetic_from_metrics`, `validate_no_synthetic_data` under Rule `R-MD-11`), evaluation splits and leakage audit engine (`src/compintel/evaluation/splits.py`, `src/compintel/evaluation/leakage.py` supporting 4-way temporal-grouped nested splits and adversarial leakage detection), evaluation metrics and bootstrap uncertainty quantification engine (`src/compintel/evaluation/metrics.py`), evaluation pre-registration specification (`experiments/preregistration/v1.yaml`, SHA-256: `277610fe03d219fd9a5da9e9e969adb7c5505bc8a2dd34b9522d1964f1dd6fb4`) and final-eval lock enforcement engine (`src/compintel/evaluation/lock.py`, `scripts/run_final_eval.py`, `make final-eval`), baseline models suite (`src/compintel/models/baselines/empirical.py` Rung A empirical conditional quantiles with hierarchical backoff ladder, backoff path audit, and thin-evidence abstention;
